Privacy Policy

Calendar Digest · last updated 19 September 2026

Scope

Calendar Digest is a private, single-user automation operated by the individual who installed it. It is not offered publicly, has no other users, and processes no data belonging to anyone other than its operator.

Data the application accesses

  • Google Calendar (read-only) — event titles, times, locations and descriptions, limited to the calendars the operator has explicitly connected.
  • Gmail (send only) — used solely to email the generated summary to the operator. The application cannot read, search, modify or delete email.
  • Public reference data — anonymously fetched public information such as published schedules, maps and routing data, and weather forecasts, used to add travel-time and weather context to the summary.

How data is used

Calendar data is read only to compose the summary: per-day schedules, the first and last commitment of each day, travel time between consecutive locations, and scheduling overlaps. That summary is the only output the application produces.

Storage and security

The application runs on a private server controlled by the operator. The OAuth credential it uses to reach Google is stored on that server, is not transmitted to any third party, and is revocable by the operator at any time. Calendar contents are held in memory only long enough to compose a summary; the application maintains no long-term archive of calendar data.

Sharing

Data is not sold, rented, traded, published, or disclosed to any third party. It is not used to serve advertising, is not used to determine creditworthiness or for lending purposes, and is not used to train machine-learning models.

Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Access ends immediately when the operator revokes the application at myaccount.google.com/permissions, or deletes the stored credential on the server. Either action permanently ends the application's ability to reach the connected account. Previously generated summaries can be deleted at the operator's discretion.

Changes

This policy may be updated as the application changes. The current version always appears at this address.
