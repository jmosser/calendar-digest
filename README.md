# calendar-digest

Public pages for the Calendar Digest app: what it is, its privacy policy and its terms of use.

Google's OAuth consent screen requires a publicly reachable privacy policy, so these pages are served
from this repository by GitHub Pages:

- https://jmosser.github.io/calendar-digest/
- https://jmosser.github.io/calendar-digest/privacy.html
- https://jmosser.github.io/calendar-digest/terms.html

**This repository is the source of truth for these pages — edit them here.** They are plain static
HTML with no build step: commit to `main` and GitHub Pages republishes within a minute. URLs on the
consent screen must stay stable, so keep the filenames as they are.

The personalised variant of the same pages lives with the digest itself and is never published from
here.
