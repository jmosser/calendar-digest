Calendar Digest

A single-user scheduling assistant.

What this is

Calendar Digest is a private automation that generates a short weekly schedule summary for the person who operates it. It reads the calendar accounts that its operator has explicitly connected and produces a plain summary of the coming week: what is scheduled on each day, the first and last commitment of each day, and where commitments overlap. The summary is delivered by email.

What it is not

  • It is not a public service. There is no sign-up, no user accounts, and no other users.
  • It does not sell, share, republish, or aggregate calendar data.
  • It cannot read email. The only mail permission it requests is the ability to send.
  • It cannot modify anything: calendar access is read-only.
  • It has no analytics, no advertising, and no third-party trackers.

Google user data

This application requests exactly two Google permissions:

  • calendar.readonly — to read event details on calendars the operator has connected, so the weekly summary can be written.
  • gmail.send — to deliver that summary by email.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
